# Landing Page HSK An Châu V1.4

Bản mẫu tuyển sinh HSK 1–3 của An Châu Education.

- Giao diện: cam/vàng, infographic và hiệu ứng chuyển động.
- Ảnh: lớp học và tư vấn thực tế đã được chỉnh sáng, tối ưu WebP.
- Trang chính: `index.html`. Các hình tại `assets/`.
- Tên miền dự kiến: https://hsk.anchaugroup.com.vn
- GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

**CHƯA NHẬN LEAD THẬT:** Form chỉ là demo, chưa lưu dữ liệu, chưa có CRM và Telegram. Không phát hành QR tuyển sinh chính thức trước khi tích hợp backend, kiểm tra quyền sử dụng ảnh, chính sách dữ liệu và lịch khai giảng.

Nguồn phiên bản: `phonganh99/an-chau-marketing/hsk-landing`; chuyển sang repo riêng để không ảnh hưởng trang quản lý Marketing.
